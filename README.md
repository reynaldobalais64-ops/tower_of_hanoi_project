# Tower of Hanoi — Mouse-Controlled Project

## How to run
1. Extract this folder.
2. Open `index.html` in your browser (double-click it), or open the folder in VS Code.
3. Click a tower to select its top disk.
4. Click another tower to move the disk.
5. Use **Reset game** to restart or change the number of disks.

## Files
- `index.html` — game structure
- `style.css` — visual design
- `script.js` — game logic and mouse controls

This version runs directly in a browser and does not require installing a server.
